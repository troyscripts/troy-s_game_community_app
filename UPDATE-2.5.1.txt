UPDATE 2.5.0 -> 2.5.1

1. Stop de bot en maak een back-up van je database.
2. Kopieer de inhoud van deze ZIP naar de hoofdmap van de bot.
   Vervang bestaande bestanden op hetzelfde pad; voeg nieuwe bestanden toe.
3. Verwijder de 2 bestanden uit VERWIJDERDE-BESTANDEN.txt.
4. Behoud je eigen .env, config/defaults.js en databasebestanden.
5. Start de bot. Het nieuwe command wordt automatisch geregistreerd.
   Als registratie mislukt: npm run deploy en de consolemelding controleren.
6. Controleer /config bekijken. Eerdere database-instellingen zijn weer actief.
   Stel gewenste wijzigingen in met /config instellen.

Nieuw: /reset-voortgang bevestigen:Ja
Dit reset uitsluitend de huidige server: level 1, 0 XP, 0 berichten,
wallet/bank op 0, XP- en economy-cooldowns gewist, open rekeningen geannuleerd.
Alleen toegankelijk met dezelfde Owner-/Developer-toegang als /config.
Discord-rollen blijven staan. De update zelf reset GEEN gebruikersgegevens.

Geen nieuwe dependencies. Het pakket bevat geen .env of database.
